# 参考

本节是文档的查阅层：精确的参数、变量、命令和配置键，均提炼自 dsh-cc
源码。每页只说明某项东西是什么、做什么——没有教程，也没有编造的默认值。
当某个行为是部分支持或缺失时，页面会如实说明。

- [/zh/reference/cli](/zh/reference/cli) —— `dsh-cc` 可执行文件在启动 `dsh --profile tui` 之前接受的参数。
- [/zh/reference/env-vars](/zh/reference/env-vars) —— 启动器与 TUI 插件之间的 `DSH_CC_*` 环境变量契约。
- [/zh/reference/commands](/zh/reference/commands) —— TUI 中可用的斜杠命令。
- [/zh/reference/permission-modes](/zh/reference/permission-modes) —— 权限模式以及确认提示如何呈现。
- [/zh/reference/settings](/zh/reference/settings) —— 设置级联。
- [/zh/reference/mcp-config](/zh/reference/mcp-config) —— MCP 服务器配置。
- [/zh/reference/extension-formats](/zh/reference/extension-formats) —— 支持的扩展格式。
- [/zh/reference/compatibility](/zh/reference/compatibility) —— dsh-cc 与 Claude Code 的真实关系。

如果你从快速上手过来，请先看 [/zh/reference/cli](/zh/reference/cli)；在假设
Claude Code 的习惯可以直接沿用之前，先读
[/zh/reference/compatibility](/zh/reference/compatibility)。
