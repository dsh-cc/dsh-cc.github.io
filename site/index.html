Open-source coding agent environment

Claude Code-style workflows.
Your models.

dsh-cc turns DeepSeek Harness into a batteries-included coding environment for everyday development. Keep familiar project assets and interaction patterns while choosing the models, tools, permissions, and agent composition that fit your environment.

Quick start 
# install DeepSeek Harness and the dsh-cc launcher
$ npm install -g @deepseek-ai/dsh @dsh-cc/cli
$ dsh-cc

Reuse familiar workflows

.claude/agents, SKILL.md, CLAUDE.md, hooks, permissions, slash commands, and resumable sessions — carry your existing project assets over as-is.

Bring your own model strategy

Route stable aliases like sketch, draft, blueprint, and masterplan to any provider/model pair your dsh deployment supports.

Run a complete coding loop

TUI, MCP, memory, subagents, background tasks, worktrees, structured output, and deferred tool discovery — the full loop, out of the box.

Stay composable

Installed through native dsh profiles and plugins — no permanent DeepSeek Harness fork to maintain.

Official packages only: every dsh-cc package is published under the @dsh-cc scope on npm (e.g. @dsh-cc/cli). Anything outside that scope is not affiliated with this project.
